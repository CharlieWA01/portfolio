# Journal

One file per work session or topic, named `YYYY-MM-DD-<topic>.md`.
Claude writes them as part of each task.

## Template

```markdown
# YYYY-MM-DD: <topic>

## Goal
What this session set out to do.

## What was done
The steps, in order, with the reasoning behind any choice.

## Problems and fixes
What went wrong, what it turned out to be, and how it was fixed.

## How it was verified
Commands run and what the output showed (no secrets, IDs as last 4 digits).

## Cost impact
What this adds to the monthly bill, if anything.
```
