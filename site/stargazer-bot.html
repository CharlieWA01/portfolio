How this page works

A small AWS Lambda checks the bot on Lichess every 5 minutes while it plays and records each game. Each night another saves the day's games to S3 and works out these stats with Athena (SQL over the saved files). Both write a small JSON file that this page reads from this same site: there's no API behind it, and it costs about 5 cents a month.

The engine's source code is on GitHub.
